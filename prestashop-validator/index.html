03 / The workflow

How it works

  1. Read the export

    Load the raw PrestaShop worksheet and confirm required columns.

  2. Standardize values

    Normalize numeric fields, categories, active flags, and dates.

  3. Validate product data

    Check references and duplicates, tax rules, prices, quantities, URL and EAN13 formats, and metadata.

  4. Prepare the report

    Write formatted valid and invalid worksheets with the issues found.
