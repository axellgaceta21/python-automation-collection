05 / Website Auditing

SEO Audit Automation

Organize common technical and on-page SEO checks in one report.

This Python script reads a URL list, requests the pages, and records HTTP and on-page findings in a structured Excel audit.

03 / The workflow

How it works

  1. Read the URL list

    Load website URLs together with their page types, priorities, and notes.

  2. Request each page

    Validate URL formats, follow redirects, and capture response status.

  3. Inspect page elements

    Review metadata, headings, canonical and robots tags, image ALT text, and estimated word count.

  4. Export the findings

    Write the audit and issue details into a formatted Excel report.
