03 / The workflow

How it works

  1. Read the catalog

    Load the raw product worksheet and verify the required columns.

  2. Normalize product fields

    Standardize text, categories, prices, stock values, status, and dates.

  3. Audit catalog quality

    Check duplicate SKUs, positive prices, stock thresholds, URL formats, and description completeness.

  4. Export the audit

    Create formatted valid and invalid product worksheets with issue descriptions.
