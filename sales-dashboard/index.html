03 / The workflow

How it works

  1. Read the orders

    Load the raw order worksheet from the source Excel workbook.

  2. Validate and organize

    Clean order fields, check required values, and separate records with issues.

  3. Build the reporting views

    Aggregate sales and calculate dashboard totals from paid orders.

  4. Export the workbook

    Write reporting worksheets, then apply Excel formatting and charts.
