03 / The workflow

How it works

  1. Read the workbook

    Load customer and order worksheets from the original Excel file.

  2. Standardize values

    Normalize names, emails, phones, dates, and status values.

  3. Check the records

    Flag missing fields, invalid values, duplicate customer IDs, and duplicate order combinations.

  4. Export the results

    Write formatted valid and invalid worksheets with issue details.
